# Gherwin Pacheco — Software Developer Portfolio

Personal portfolio of **Gherwin Pacheco**, Software Developer specializing in Manufacturing Execution (MES) and Warehouse Management (WMS) systems, real-time operational dashboards, high-volume SQL query optimization, shop-floor integrations, and full-stack web development (`C#`, `.NET Core MVC (.NET 8)`, `VB.NET`, `PHP`, `React.js`, `Next.js`, `MySQL`, `SQL Server`, `n8n`).

## Tech Stack
- **Framework:** Next.js 14 (App Router, Static Export)
- **UI & Styling:** React 18, Tailwind CSS, Radix UI, Lucide Icons, FontAwesome
- **Contact Integration:** EmailJS (`@emailjs/browser`)
- **Deployment:** GitHub Pages (`gh-pages`)

## Getting Started

```bash
# Start local development server (http://localhost:3000)
npm run dev

# Build static production export to ./dist
npm run build

# Deploy to GitHub Pages
npm run deploy
```
